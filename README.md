# Bunonkari

An interactive weave designer for textile students. Draw a weave, see it as 3D yarns and as a flat fabric, read its drafting plan and lifting plan, and practice with exercises.

**Live site:** https://shamsalnayaz.github.io/bunonkari/

## What it does
- 24 preset weaves in groups (basic, twill family, satin and sateen, rib, textured, fancy) and a paint-your-own grid with undo and redo
- 3D yarn view and a flat fabric view that react to yarn size, crimp, twist, slub, hairiness, roughness, sheen and lighting
- Drafting plan and lifting plan shown live next to the weave, with the repeat unit outlined
- Practice exercises: weave to drafting plan, drafting plan to weave, name the weave, find the repeat, number of shafts, copy the weave
- Dark and light mode; export as JSON, CSV, text or PNG

## How to update the site
Edit `index.html` (or replace a file in `images/`) on GitHub and choose **Commit changes**. GitHub Pages republishes in about a minute.
